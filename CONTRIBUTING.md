# Contributing

Thanks for helping. This is a prototype, so short issues and small pull requests work best.

## Issues

- Bugs, ideas and build reports each have a template under "New issue".
- Photos of your build are very welcome; remove location data from them first.
- Security problems in the firmware go through a private report, not a public issue: see [SECURITY.md](SECURITY.md).

## Pull requests

- Keep each pull request to one topic and describe what you actually tested (printed, flashed, or only regenerated).
- Add a line to `CHANGELOG.md` under "Unreleased".
- CI regenerates the parts, checks that every mesh is watertight and runs `reuse lint`.

## How parts are regenerated

The STL and 3MF files are generated by the Python scripts in `hardware/cad/`, so change the scripts rather than editing meshes by hand.

```
pip install trimesh manifold3d shapely mapbox_earcut rtree numpy scipy networkx lxml matplotlib
python hardware/cad/build_drivetrain.py
python hardware/cad/build_disc_v2_chute.py
python hardware/cad/check_meshes.py
```

Commit the regenerated files in `hardware/stl/`, `hardware/3mf/` and `hardware/cad/drivetrain.json` together with the script change.

## Conventions

- Units: millimetres.
- Frame: Z-up, with Z=0 at the top face of the box lid. X runs along the long side of the box and Y along the short side (see `hardware/cad/layout_v3.json`).
- Drivetrain parts are modelled at their assembled height, with X=Y=0 on the shaft axis.
- Part names are Italian and kept as they are, for example `disco` (disc), `albero_mozzo` (shaft and hub), `passante_stagno` (sealed bushing), `scivolo` (chute) and `test_scanalato` (spline test).
